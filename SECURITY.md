# Security policy

This project is for authorized defensive testing and research only.

Please do not use it against third-party systems, production services, or
systems without written permission. Do not add exploit code, payloads, memory
corruption triggers, denial-of-service generators, or credential collection.

To report a problem in this repository, open a private security report through
GitHub if available. For PHP vulnerabilities, follow the [PHP security
process](https://wiki.php.net/security) and contact the PHP security team.
